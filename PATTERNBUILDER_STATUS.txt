🎨 CARACTERÍSTICAS PRINCIPALES
═══════════════════════════════════════════════════════════════════════════════

✅ Grupo A: Anclas y Posición
   - startOfLine()    → Añade ^
   - endOfLine()      → Añade $
   - wordBoundary()   → Añade \b

✅ Grupo B: Contenido
   - find(texto)           → Búsqueda literal con auto-escaping ⭐
   - digit()/word()/whitespace()/tab()  → Clases predefinidas
   - any()            → Comodín .
   - range(a, z)      → Rangos [a-z]

✅ Grupo C: Cuantificadores
   - exactly(n)       → Exactamente n {n}
   - maybe()          → Opcional ?
   - oneOrMore()      → Uno o más +
   - anyAmount()      → Cero o más *
   IMPLEMENTACIÓN: Opción A (trackeo de último token)

✅ Grupo D: Lógica Negativa
   - not(caracter)    → Negación [^caracter]
   - or(patron)       → Alternancia |

✅ La Joya: cut()
   - cut(delim)       → Captura automática ⭐⭐⭐
   - cut(open, close) → Delimitadores diferentes
   GENERADO: delim([^delim]*)finDelim

✅ Métodos de Acción
   - matches(string)      → Test booleano
   - get(string)          → Extrae coincidencias + grupos
   - replace(string, val) → Reemplaza
   - toRegex()            → RegExp compilada
   - toString()           → Patrón como string

✅ Debug Avanzado
   - debug()    → Imprime regex + explicación humanizada 🔍

✅ Compatibilidad de Flags
   - global()      → Bandera g
   - insensitive() → Bandera i
   - multiline()   → Bandera m
   - addFlag(f)    → Personalizado


🏗️ ARQUITECTURA
═══════════════════════════════════════════════════════════════════════════════

Estructura de Datos Interna:
  {
    prefixes: '',       // Inicio del patrón (ej. ^)
    source: '',         // Cuerpo del patrón
    suffixes: '',       // Final del patrón (ej. $)
    flags: [],          // Banderas [g, i, m, ...]
    __lastToken: ''     // Trackea último token (Opción A)
  }

Flujo de Compilación:
  prefixes + source + suffixes + flags → new RegExp() → Ejecución

Método Privado: __escape()
  - Escapa caracteres especiales: [](){}.*+?^$|\
  - Usa regex: /[[\(){}.*+?^$|\\]/g
  - Sustituye: cada carácter → \$&

Encadenamiento Fluido:
  - Todos los métodos retornan 'this'
  - Permite cadenas indefinidas
  - Compatible con async/await


✨ CARACTERÍSTICAS ESPECIALES
═══════════════════════════════════════════════════════════════════════════════

1. ESCAPING AUTOMÁTICO EN find()
   ✅ No escribas \, PatternBuilder lo maneja
   Ejemplo:
     .find('img.png')  → /img\.png/
     .find('[test]')   → /\[test\]/
     .find('(a|b)')    → /\(a\|b\)/

2. CAPTURA AUTOMÁTICA EN cut()
   ✅ Genera grupos de captura sin escribir paréntesis
   Ejemplo:
     .cut('"')  → /"([^"]*)"/
     Match[1]   → contenido entre comillas

3. IMPLEMENTACIÓN OPCIÓN A - CUANTIFICADORES
   ✅ Trackeo de último token (más limpio y performante)
   Ventajas:
     - Mejor rendimiento (sin re-parsing)
     - Más legible y mantenible
     - Menos propenso a errores

4. DEBUG HUMANIZADO
   ✅ Método debug() que imprime:
     - Componentes internos (prefixes, source, suffixes, flags)
     - Regex generado (/patrón/)
     - Explicación humanizada en lenguaje natural

💡 EJEMPLOS RÁPIDOS
═══════════════════════════════════════════════════════════════════════════════

Email Validation:
  pattern.startOfLine()
    .word().oneOrMore()
    .find('@')
    .word().oneOrMore()
    .find('.')
    .word().oneOrMore()
    .endOfLine()
    .matches('user@example.com')  // true

Capturar Contenido:
  pattern.cut('"')
    .get('message="Hello"')[1]  // "Hello"

Búsqueda Global:
  pattern.digit().oneOrMore().global()
    .get('Price: $10, Total: $50')  // ['10', '50']

Case-Insensitive:
  pattern.find('hello').insensitive()
    .matches('HELLO')  // true

Alternancia (OR):
  pattern.find('javascript').or('python').or('rust')
    .matches('I love python')  // true

🎓 CONSIDERACIONES TÉCNICAS
═══════════════════════════════════════════════════════════════════════════════

Opción A vs Opción B (Cuantificadores):
  ✅ ELEGIDA: Opción A - Trackeo de último token
  Razones:
    - Más limpio internamente
    - Mejor rendimiento (sin regex en source)
    - Menos bugs potenciales
    - Más fácil de mantener

Escaping:
  ✅ Caracteres escapados: [](){}.*+?^$|\
  ✅ Usa regex: /[[\(){}.*+?^$|\\]/g
  ✅ Método: .replace(/[[\(){}.*+?^$|\\]/g, '\\$&')

cut() - Estructura Sándwich:
  ✅ Pan de arriba: delimitador escapado
  ✅ La carne (captura): paréntesis ( )
  ✅ El relleno: [^delimitador]*
  ✅ Cierre: paréntesis ) 
  ✅ Pan de abajo: delimitador escapado
  Resultado: delim([^delim]*)finDelim
